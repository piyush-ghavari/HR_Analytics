# HR Analytics Dashboard using Tableau

## Introduction
This project leverages the **HR Analytics** dataset to create an interactive Tableau dashboard. The dashboard provides insights into employee performance, 
attrition rates, salary distribution, and other key HR metrics, enabling HR professionals to make data-driven decisions to improve workforce strategies.


## Dataset
- **Source**: HR Analytics dataset (can be obtained from Kaggle or other platforms)
  (https://www.kaggle.com/datasets/rishikeshkonapure/hr-analytics-prediction)

## Setup and Installation
1. Install **Tableau** (if not already installed) from [Tableau Downloads](https://www.tableau.com/products/desktop).
2. Download the **HR Analytics** dataset from Kaggle or another data source.
3. Import the dataset into Tableau.
4. Open the provided Tableau workbook file or start building your own dashboard using the dataset.
5. Use various Tableau features like filters, calculated fields, and visualizations to analyze trends and create the dashboard.

### Insights

1. **Gender and Attrition**:  
   In the HR Analytics dataset, **male employees** show a **higher attrition rate** compared to female employees, indicating that more male employees are leaving the company.

2. **Department-wise Attrition**:  
   The **Human Resources** department has a **lower attrition rate** compared to other departments, suggesting that employees in HR are more likely to stay with the company.

3. **Job Satisfaction for Sales Executives**:  
   **Sales Executives** have a **job satisfaction score of 4**, indicating relatively high satisfaction among employees in this role.

---

### Recommendations

1. **Focus on Male Employee Retention**:  
   Given the higher attrition rate among **male employees**, the company should explore retention strategies specifically targeting male employees, such as career development programs or work-life balance initiatives.

2. **Enhance Engagement in Other Departments**:  
   Since the **Human Resources** department has a lower attrition rate, HR policies that contribute to higher job satisfaction and retention in this department could be replicated in other departments to improve retention company-wide.

3. **Leverage High Job Satisfaction in Sales Executives**:  
   With **Sales Executives** reporting high job satisfaction, the company can consider using this group as role models or champions for promoting positive work culture and engagement across other departments.
